# CBTPRDM_TP03 — Rastreamento Logístico (.NET MAUI + MVVM)

Dupla: André Luiz Nascimento de Andrade e João do Valle Seixas Paula

Aplicativo de rastreamento de pacotes com dados fictícios.

## Estrutura (MVVM)
- `Models/` — `PackageModel`, `TrackingEvent`
- `Services/` — `ITrackingService` e `MockTrackingService` (busca simulada)
- `ViewModels/` — `TrackingViewModel` (página inicial), `ResultViewModel` (resultado)
- `Views/` — `HomePage` (digitar código), `ResultPage` (status e histórico)
